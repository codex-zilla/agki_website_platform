{% comment %} The client-side lookup script that used to live here has been removed (plan 1.7, design finding appointments #2). It did not work and it made the page not work: * it rewrote whatever the patient typed into MediBook's MB-YYYY-XXXXX format, so a real AGKI- booking ID could never be entered; * its submit handler cancelled the submit event unconditionally and then returned, so the form was never actually submitted; * the handler was left unterminated, which nested every later listener inside it and made `errorMessage` - an element id that exists nowhere in this page - throw on the first keystroke. The form is now a plain HTML POST to a real view. Nothing about finding an appointment should depend on JavaScript running correctly. A template comment rather than an HTML one: this is a note to whoever reads the template next, and there is no reason to ship it to every visitor's browser. {% endcomment %}
