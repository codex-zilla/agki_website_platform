{% comment %} The page's JavaScript, reduced to the two modal helpers that do something. It was ~200 lines, and the interesting part is that most of it could never have run: `confirmPatientApproval()` read three checkbox ids that do not exist on the page, `savePatientNote()` read two more, and both then popped an alert saying the thing had been saved -- having called nothing. A `DOMContentLoaded` block also bound "Opening appointment scheduler..." to `.action-btn.success`, which is now the real "Mark as completed" submit button. Removing the approval modal above would have broken the note modal too, for a reason worth naming: an `addEventListener` on the removed element throws, and everything after it in the same script never runs. That is exactly how the public booking form's fake submit handler stayed harmless for so long. {% endcomment %} {% endblock %}
